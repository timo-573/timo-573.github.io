# Timo Mayer — Research Portfolio

Personal academic website for Timo Mayer, Information Systems researcher at FAU Erlangen-Nürnberg.

## Structure

- `index.html` — research-focused landing page
- `about.html` — biography and academic trajectory
- `publications.html` — peer-reviewed work and research pipeline
- `topics.html` — research topics and questions
- `contact.html` — contact details and academic profiles
- `impressum.html` and `datenschutz.html` — legal information

The site is dependency-free and deployed through GitHub Pages at `timomayer.de`.
